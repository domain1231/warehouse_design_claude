5-1 JSON 백업 — 유일하게 밖으로 나가는 사본

  1. ① 줄의 「JSON 백업」을 누르면 warehouse_project_v2_3_6_2026-11-16.json처럼 날짜가 붙은 파일이 다운로드됩니다.
  2. 다운로드 폴더에 파일이 실제로 있는지 확인하고, 사내 드라이브 등 다른 곳에 한 부 더 둡니다.
  3. 되살릴 때는 「불러오기」로 그 파일을 고릅니다. 프로젝트 전체가 바뀌므로 저장 안 된 작업이 있으면 「교체 전 현재 작업 보호」 창이 먼저 뜹니다(코스 0-5).

5-3 실습 — 2개 지우고 되돌리기

  1. 랙 5개 중 2개를 상자로 골라 「삭제」를 누릅니다. 확인 창이 뜹니다.
    랙 2개를 삭제합니다. 자동 백업 후 삭제되며 ↶로 되돌릴 수 있습니다.
  2. 확인하면 상태 줄이 「전체 3랙」이 됩니다. Ctrl+Z → 「전체 5랙」, Ctrl+Y → 다시 「전체 3랙」.
  3. 「이전 버전·백업」을 열면 「대량 객체 삭제 전」 백업이 생겨 있습니다.

「현재 백업 후 복원」을 누르면 확인 창이 한 번 뜹니다.

선택한 이전 버전으로 복원하면 현재 작업이 변경됩니다. 현재 상태를 먼저 백업하고 복원합니까?
「이 버전 JSON」은 복원하지 않고 그 시점 내용을 파일로만 받습니다. 복원하기 전에 내용을 확인하고 싶을 때 쓰세요.
시각은 한국 시각으로 표시됩니다(예: 2026. 11. 25. 오전 10:15:17). 마우스를 올리면 저장된 원래 값(세계 표준시, …Z)이 보입니다. alpha.13까지는 세계 표준시로만 표시했습니다.

5-4 실습 — 복제로 바뀐 AFTER만 되살리기

코스 4에서 「BEFORE → AFTER 복제」를 다시 하면 작업하던 AFTER가 BEFORE 복사본으로 바뀝니다(기본 처리). 교육용 예시에서는 7랙이던 AFTER가 3랙이 되었습니다.

  1. ⑧ 줄의 「하단 전체 펼치기」를 누릅니다.
  2. 「Excel 가져오기·자동 백업 이력」을 펼치면 「보관 중인 대상별 백업」에 시각·대상(AFTER)·방식(BEFORE→AFTER 복제)이 나옵니다.
  3. 되살릴 시점의 「이 상태로 복원」을 누르고 확인합니다.
    AFTER의 2026-11-16T11:28:42.498Z 이전 상태를 복원합니까? 현재 대상 상태도 다시 백업합니다.
  4. 상태 줄이 「전체 7랙」으로 돌아오고, BEFORE는 그대로입니다.
