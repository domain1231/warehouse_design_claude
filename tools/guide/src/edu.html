수료 확인 퀴즈 (답은 눌러서 확인)

1. 상단이 「○ 저장되지 않은 변경사항 · UNSAVED」입니다. 가장 먼저 할 일은?

「프로젝트 저장」(또는 Ctrl+S)을 누르고 「● 모든 변경사항 저장됨 · SAVED」로 바뀌는지 확인합니다. → 0-2

2. 로케이션 7F-C-5-3-1에서 "3"은 무엇인가요?

선반 번호입니다. 7F=층, C=열, 5=랙 번호, 1=자재 위치. → 2-0

3. 랙의 X에 3을 넣으면 랙의 어느 지점이 3m에 놓이나요?

랙의 왼쪽 위 모서리(회전 전 기준)입니다. 가운데가 아닙니다. → 1-6

4. AFTER에서만 창고 치수를 바꾸면 어떤 문제가 생기나요?

창고 치수는 BEFORE·AFTER에 따로 저장되므로 비교 면적과 면적 사용률이 서로 다른 기준이 됩니다. BEFORE에서 치수를 정한 뒤 복제합니다. → 4-1

5. 브라우저 기록을 지운 뒤에도 남는 사본은 무엇인가요?

직접 받아 둔 JSON 백업 파일뿐입니다. 자동 저장과 자동 백업은 브라우저 안에 있습니다. → 5-1

A-6 화면 문구 색인 — "이 문장이 떴어요"

화면에 뜬 문장을 그대로 찾을 수 있게 모았습니다. 검색창(/)에 문장 앞부분을 넣어도 됩니다. 거부는 아무것도 바뀌지 않았다는 뜻이고, 확인 창은 누르기 전까지 바뀌지 않습니다.
