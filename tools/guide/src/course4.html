코스 4

개선안 비교 — BEFORE를 지키고 AFTER에서 바꿔 보기

목표 이 코스를 마치면 ① 현재 창고(BEFORE)를 기준안으로 잠그고 ② 복사본(AFTER)에서 개선안을 만들고 ③ 「비교」 창의 숫자를 바르게 읽어 보고할 수 있습니다.

약 20분
30초 요약
{{SVG_BA}}
  1. BEFORE는 처음부터 잠겨 있습니다. 현재 창고를 입력할 때만 잠금을 풀고, 다 넣으면 다시 잠급니다.
  2. 창고 치수도 BEFORE와 AFTER가 따로 가집니다. 치수는 BEFORE에서 먼저 정하고 복제하세요.
  3. 비교 창의 숫자는 입력한 만큼만 계산됩니다. 「미확인」은 0이 아니라 "모름"입니다.

4-1 BEFORE(현재안) 만들기

  1. ⑥ 배치 전환 줄에서 「BEFORE 보기」를 누릅니다. 제목이 「BEFORE · 조회 / 원본 잠금」으로 바뀝니다.
  2. 「BEFORE 잠금 해제」를 누르면 확인 창이 뜹니다. 내용을 읽고 확인합니다.
    개선 전 배치를 수정하면 개선 효과 분석의 기준 데이터가 변경됩니다. BEFORE 잠금을 해제합니까?
  3. 제목이 「BEFORE · 편집」, 옆에 「BEFORE 수정 허용」이 보이면 입력할 수 있습니다.
  4. 창고 치수부터 넣고(코스 1-3), 현재 랙 위치를 입력합니다. Excel이 있으면 코스 2에서 「가져오기 대상」을 「BEFORE — 개선 전」으로 고르면 됩니다.
  5. 다 넣었으면 「BEFORE 잠그기」를 누릅니다.
잠긴 BEFORE는 고칠 수 없습니다. 잠근 채 랙을 놓거나 옮기면 아래처럼 취소됩니다. 실수로 기준안이 바뀌는 것을 막는 정상 동작입니다.
전체 취소: BEFORE 원본 잠금 상태입니다. 잠금 해제 후 수정하세요.

4-2 BEFORE를 AFTER로 복제

  1. 「BEFORE → AFTER 복제」를 누릅니다. 「BEFORE → AFTER 복제 미리보기」 창에 양쪽 랙 수(예: 「BEFORE 6랙 / AFTER 0랙」)와 그림이 나옵니다.
  2. 「기존 AFTER 처리」를 고릅니다.
  3. 「확인 후 독립 복제」를 누르고, 이어지는 확인 창(기존 AFTER를 백업한 뒤 교체한다는 안내)에서 확인합니다.
  4. 화면이 「AFTER · 편집」으로 바뀝니다.
「기존 AFTER 처리」언제
기존 AFTER 자동 백업 후 교체 (기본)AFTER를 새로 시작할 때. 이전 AFTER는 백업에 남음
독립 ID·생성일의 새 개선안 버전 생성 (기존 AFTER 백업)개선안 2안, 3안처럼 버전을 구분하고 싶을 때
기존 AFTER 유지 · 취소지금 AFTER를 지키고 복제를 그만둘 때
"깊은 복사"는 AFTER를 바꿔도 BEFORE가 함께 바뀌지 않는 완전히 따로인 복사본이라는 뜻입니다. 재고 기록 복사도 유지됩니다.

4-3 AFTER에서 개선안 만들기

코스 3의 방법을 그대로 씁니다. 교육용 예시에서는 윗줄 3개를 「위쪽 정렬」 → 「가로 간격」 0.2m로 맞추고, 남은 자리에 랙 2개를 추가했습니다.

편집 중인 배치는 ⑧ 화면 조작 줄의 「편집 배치」(「Before · 현재안」 / 「After · 개선안」)에서도 확인하고 바꿀 수 있습니다. 작업 전에 제목이 「AFTER · 편집」인지 꼭 보세요.

4-4 「비교」 창 읽기 — 결론부터, 근거는 아래로

⑧ 줄의 「비교」를 누르면 「Before / After 배치 비교」 창이 열립니다. 화면 폭이 1280px 이상이면 왼쪽에 결론·표, 오른쪽에 Δ 지도가 한 화면에 나옵니다. 위에서부터 읽으면 결론 → 숫자 → 근거 → 랙 하나씩 순서입니다.

실습 파일{{DL_CMP}}Excel로 만든 BEFORE(현재)와 개선 후 Excel을 불러온 AFTER · 아래 그림과 같은 상태손으로 놓은 랙(4-1~4-3 예시)은 자재 높이가 없어 용적률이 「미확인」입니다. 용적률 비교는 Excel 자료가 연결된 랙만 됩니다.

① 결론 문장 · ② KPI 카드 — 30초 판단

  • 결론 문장은 좋아진 지표를 최대 3개, 정해진 순서(평균 용적률 → 빈 랙 → 보관 가능 합계 → 80% 미만 → 저활용 랙 → 최소 통로 폭)로 고릅니다. 나빠진 지표가 있으면 아래 줄에 「⚠ 주의: …」가 따로 나옵니다.
  • ▲ = 좋아짐, ▼ = 나빠짐입니다. 숫자가 늘었다는 뜻이 아닙니다. 80% 미만 로케이션은 66 → 54로 줄었는데 「▲ −12 개선」으로 나옵니다.
  • 결론 문장은 창고 전체 지표만 봅니다. 위 예시에서 B03 랙은 −19.2%p 나빠졌지만 결론에는 나오지 않습니다. 랙 하나의 악화는 ⑦ 목록과 ⑧ 지도에서 확인합니다.

③ 출처 칩 · ④ 목적 지표 표 · ⑤ 공간 구성 막대 — 근거 확인

볼 곳확인할 것
출처 칩 3개BEFORE·AFTER가 어느 시트·기준일 자료인지, 면적 기준이 같은지. 칩에 마우스를 올리면 파일 이름과 가져온 시각이 보입니다. 한쪽에만 Excel 총면적이 있으면 「AFTER 면적 130.5㎡ 적용」처럼 버튼이 나와 같은 기준으로 맞춥니다(실행취소 가능, BEFORE가 잠겨 있으면 비활성).
목적 지표 표「BEFORE → AFTER」 한 칸과 「차이」 한 칸. 초록 ▲ = 개선, 빨강 ▼ = 악화, 흐린 줄 = 변화 없음, 색 없는 줄 = 좋고 나쁨을 정하지 않은 지표(통로 비중·공간 구성·선반 여유 용적)
공간 구성 막대바닥을 랙 · 빈 랙 · 보관 불가 · 통로 · 보관 가능 잔여로 나눈 100%. 두 막대 사이 Δ 줄에서 노란 굵은 글씨가 바뀐 구간입니다(예: 랙 −0.8%p, 빈 랙 +0.8%p).
배치 변경 줄이동·회전·신규·제거·규격 변경 수. 「신규 1」이면 AFTER에만 있는 랙이 하나
표의 공간 구성 "랙 8.8% → 랙 8.8%"와 막대의 "8.0%"가 다른 이유 표의 '랙'은 빈 랙을 포함한 랙 바닥 비율이고, 막대는 이를 랙(자재 있음) 8.0% + 빈 랙 0.8%로 나눠 보여 줍니다. 같은 숫자를 다르게 쪼갠 것이지 계산이 틀린 것이 아닙니다. "C02를 비워 빈 랙이 0.8%p 생겼다"로 읽으세요.
