코스 1

첫 창고 만들기 — 10×6m 창고에 문·기둥·랙 3개

목표 이 코스를 마치면 ① 화면의 어느 칸이 무슨 일을 하는지 알고 ② 빈 창고를 만들고 ③ 구조물과 랙을 놓은 뒤 ④ 숫자로 위치를 정확히 맞춰 저장할 수 있습니다.

약 15분
30초 요약 — 왼쪽에서 놓고, 가운데서 보고, 오른쪽에서 고칩니다
  1. 왼쪽 「02 / 배치 도구」에서 도구를 고르고 도면을 클릭하면 놓입니다. 클릭한 점이 객체의 가운데가 됩니다.
  2. 가운데 도면에서 객체를 클릭해 고르고, 끌어서 옮깁니다.
  3. 오른쪽 선택 정보에서 X·Y·폭·깊이·회전을 숫자로 고칩니다. 좌표는 창고 왼쪽 위가 0, X는 오른쪽 · Y는 아래로 커집니다.

1-1 화면 지도 — 12칸만 알면 됩니다

번호 위에 마우스를 올리면 칸 이름이 보입니다. 처음에는 ⑤ 왼쪽 설계 도구 · ⑨ 도면 · ⑫ 오른쪽 선택 정보 세 칸만 쓰면 됩니다.

1-2 빈 프로젝트 만들기

  1. ⑤ 왼쪽 패널 아래쪽의 「빈 프로젝트」를 누릅니다.
  2. 저장 안 된 작업이 있으면 「교체 전 현재 작업 보호」 창이 뜹니다. 연습이라면 「현재 프로젝트 저장 후 교체」, 업무 데이터라면 「현재 JSON 다운로드 후 교체」를 누릅니다. (코스 0-5)
빈 프로젝트의 기본 크기는 가로 24m × 세로 14m입니다. 다음 단계에서 실제 크기로 바꿉니다.

1-3 창고 크기 넣기

  1. 「가로 X (m)」에 10, 「세로 Y (m)」에 6을 넣습니다.
  2. 「치수 적용」을 누릅니다.
  3. 「계산 면적 (㎡)」과 ③ 지표 바의 「전체 창고 면적」이 60㎡인지 확인합니다.
  4. ⑧ 화면 조작 줄의 「전체 보기」를 누르면 창고가 도면 가운데에 맞춰집니다.
치수를 바꿔도 이미 놓인 객체의 좌표를 늘리거나 줄이지 않습니다. 창고를 줄여서 벽 밖으로 나간 객체는 경고로 알려 줍니다.
가로를 모르고 면적만 알면 「면적에서 치수 계산」을 펼쳐 면적과 아는 한 변을 넣습니다.

1-4 출입문·기둥 놓기

  1. 「02 / 배치 도구」에서 「◴ 출입문」을 누르고 도면의 오른쪽 아래 근처를 클릭합니다.
  2. 「▪ 기둥」을 누르고 창고 가운데를 클릭합니다.
  3. 놓인 직후 ⑫ 오른쪽에 그 객체의 정보가 열립니다. 위치·크기는 거기서 숫자로 고칩니다.
도구처음 놓이는 크기
「◴ 출입문」1.2 × 1.2m
「▪ 기둥」0.6 × 0.6m
「━ 내부 벽」3 × 0.2m
「↔ 통로」 · 「▧ 보관 불가」 · 「▱ 작업 공간」4 × 1.5m · 2 × 2m · 3 × 2m
벽에 너무 붙여 클릭하면 놓이지 않습니다. 클릭한 점이 가운데가 되기 때문에, 1.2m 문을 벽 0.25m 안쪽에 클릭하면 절반이 창고 밖으로 나갑니다. 이때 화면 아래에 이렇게 뜨고 아무것도 추가되지 않습니다.
전체 취소: 출입문 001 · 창고 경계 이탈 · 빈 곳을 다시 클릭하거나, 겹침을 허용하려면 '공간 위반을 경고 후 허용'을 켜세요.
해결 조금 더 안쪽을 클릭해 놓은 뒤, 오른쪽 X·Y 숫자로 벽에 딱 붙입니다. 기본 정책이 「새 공간 위반 차단」이라서 생기는 정상 동작입니다.

1-5 랙 3개 놓기

  1. 「추가 랙 종류」(중량랙 등)를 고르고 「폭 (m)」 1.2, 「깊이 (m)」 0.5, 「높이 (m)」 2를 넣습니다.
  2. 「▤ 랙 추가」를 누르고 도면에서 서로 떨어진 세 곳을 클릭합니다. 랙 번호는 R-001, R-002, R-003처럼 자동으로 붙습니다(도면에는 R-01처럼 짧게 표시).
  3. 다 놓았으면 「↖ 선택 / 이동」을 눌러 추가 모드를 끕니다. 안 끄면 클릭할 때마다 랙이 생깁니다.
마우스로 놓기 어렵다면 「▤ 이 랙을 도면으로 드래그」 카드를 도면으로 끌어다 놓아도 됩니다.
④ 상태 줄에 「전체 3랙 · 경계 내부 3」, 「랙 충돌 0건」이 보이면 정상입니다.

1-6 숫자로 위치 맞추기

{{COORD}}
  1. 「↖ 선택 / 이동」 상태에서 R-02를 클릭합니다. 오른쪽에 「선택 객체 1」이 열립니다.
  2. 「X (m)」에 3, 「Y (m)」에 1을 넣고 Enter를 누릅니다.
  3. R-02의 왼쪽 위 모서리가 창고 왼쪽 위에서 오른쪽 3m, 아래 1m에 놓입니다.
숫자 입력은 0.001m(1mm)까지 받고, 스냅(격자 맞춤)의 영향을 받지 않습니다. 비워 두고 Enter를 누르면 「X 값을 입력하세요 · 0.001m 단위. 기존 위치·규격을 유지합니다.」라고 알려 주고 위치는 그대로 둡니다.
회전한 랙도 좌표는 회전하기 전 왼쪽 위 기준입니다(오른쪽 패널 「좌표는 회전 전 좌상단 기준입니다.」).

1-7 마우스로 옮기기·되돌리기

  1. R-03을 눌러 잡은 채 오른쪽으로 끌었다 놓습니다. 끄는 동안 주변 객체까지의 거리가 실시간으로 보입니다.
  2. 잘못 옮겼으면 「↶ 취소」(Ctrl+Z), 다시 하려면 「↷ 다시」(Ctrl+Y)를 누릅니다.
  3. 미세 조정은 방향키(기본 0.01m), 크게 옮길 때는 Shift+방향키(기본 0.1m)를 씁니다. 간격은 왼쪽 「정밀 배치 설정」에서 바꿉니다.
하고 싶은 일누를 것 (⑪ 아래 줄)
90도 돌리기「↻ 90°」 (임의 각도는 오른쪽 「회전 (°)」)
같은 랙 하나 더「복제」
지우기「삭제」 또는 Delete 키 · 2개 이상이면 확인 창이 한 번 더 뜹니다
여러 개 고르기Shift+클릭, 또는 빈 곳에서 끌어 상자로 고르기

1-8 저장 확인

편집할 때마다 자동으로 저장되므로, 마지막에 확인만 하면 됩니다. Ctrl+S를 누르면 이미 저장된 경우 「변경 없음 · 이미 저장됨 (SAVED)」이라고 알려 줍니다.

오늘 만든 창고를 다른 PC에서 쓰거나 남에게 보내려면 「JSON 백업」으로 파일을 받으세요. HTML 파일만 보내면 작업은 따라가지 않습니다.

1-9 참고 도면 깔고 축척 맞추기

종이 도면이나 CAD 캡처가 있으면 배경으로 깔고 그 위에 따라 그리면 훨씬 빠릅니다.

  1. ⑤ 「04 / 참고 도면 배경」을 펼치고 「이미지 불러오기」로 PNG·JPG·WEBP를 고릅니다. 처음에는 창고 전체 크기에 맞춰 늘려 깔립니다.
  2. 「투명도」를 올려 잘 보이게 합니다.
  3. 도면에 길이를 아는 선(예: 5m 눈금)이 있으면 「보정할 두 점 사이 실측 거리 (m)」에 5를 넣고 「도면 위 두 점으로 축척 보정」을 누른 뒤, 그 선의 양 끝을 차례로 클릭합니다.
    배경 축척을 보정했습니다. 위치는 별도로 조정할 수 있습니다.
  4. 위치가 어긋나면 「배경 X (m)」·「배경 Y (m)」로 옮깁니다. 다 쓰면 「배경 제거」.
보정은 가로·세로 같은 비율로만 맞춥니다. 찌그러진 스캔 도면은 먼저 바로잡아 오세요. 배경은 그림일 뿐이라 벽·기둥으로 인식되지 않습니다. 구조물은 따로 놓아야 검사에 들어갑니다.

1-10 구역 표시와 거리 재기

도구쓰는 곳검사
「▧ 보관 불가」 (처음 2×2m)소화전 앞, 배전반, 바닥 파손 구역랙을 겹치면 막힘
「▱ 작업 공간」 (처음 3×2m)포장대, 검수 구역, 대기 공간면적 지표에 포함
「⌁ 거리 측정」두 점 사이 거리 확인배치에 영향 없음
보관 불가 구역 위에 랙을 놓으려 하면 막힙니다.
전체 취소: 보관 불가 001 ↔ R-002 · 객체 충돌 · 빈 곳을 다시 클릭하거나, 겹침을 허용하려면 '공간 위반을 경고 후 허용'을 켜세요.

「⌁ 거리 측정」을 누르고 두 점을 클릭하면 하단 「공간검토」 칸에 「두 점 거리 8 m · ΔX 8 m · ΔY 0 m」처럼 거리와 가로·세로 차이가 나옵니다.

오른쪽 ⑫ 「공간 지표」의 「보관 불가 / 문 안전 구역」, 「통로 / 작업 구역」, 「중복 제외 잔여 면적」이 이 구역들을 반영합니다. 겹친 구역은 잔여 면적에서 한 번만 뺍니다.

벽 옆에 문을 놓으려는데 안 놓임클릭점이 가운데라 문 절반이 창고 밖으로 나감안쪽에 놓고 X·Y 숫자로 붙이기
