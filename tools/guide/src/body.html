0-0 프로그램 받기·열기·둘 곳 정하기

  1. 프로그램은 HTML 파일 하나입니다. 설치할 것도, 인터넷도 필요 없습니다.
  2. 먼저 쓸 브라우저를 정합니다. Chrome이든 Edge든 앞으로 한 가지만 씁니다. 파일은 D:\창고배치\처럼 찾기 쉬운 폴더에 둡니다.
  3. 파일을 그 폴더에 넣고 Chrome 또는 Edge로 엽니다(더블클릭, 또는 브라우저 창으로 끌어다 놓기).
  4. 앞으로도 같은 브라우저로 엽니다. 파일 이름이나 폴더는 바꿔도 이전 작업이 그대로 보입니다. 다른 브라우저로 열면 보이지 않습니다(0-3).
  5. 막히면 오른쪽 위 「사용 안내」를 누르면 프로그램 안의 요약 도움말이 열립니다.
왜 브라우저가 중요한가? 이 프로그램은 작업을 파일이나 서버가 아니라 지금 연 브라우저 안에 저장합니다. Chrome과 Edge는 저장 공간이 따로입니다. 반대로 같은 브라우저에서 연 이 프로그램 파일은 위치·이름과 관계없이 모두 같은 저장 공간을 씁니다. 그래서 업무용 PC에서 교육용 사본을 열어 「빈 프로젝트」나 실습 파일을 불러오면 업무 프로젝트가 교체됩니다(교체 전 보호 창이 뜹니다). 실습 전에는 「JSON 백업」을 먼저 받으세요.

0-1 내 프로그램 버전 확인

오른쪽 위 「프로그램 정보」를 누릅니다. 프로그램 버전과 프로젝트 데이터 버전이 따로 표시됩니다. 데이터 버전이 2.3.6이면 예전 버전과 같은 JSON 형식을 씁니다.

왜 중요한가요? 설명서와 화면이 다르면 가장 먼저 버전을 확인합니다. 이 설명서는 v2.5.0-alpha.14 기준입니다.

0-2 저장 상태 읽기 — 신호등 하나만 보면 됩니다

저장 상태는 위쪽 버튼 줄 가운데에 항상 표시됩니다. 바로 아래 줄에는 마지막으로 확인된 저장 시각이 나옵니다.

0-3 예전 데이터 옮기기 (v2.4.1·v2.3.6 사용자)

내 상황에 맞는 길을 따라가세요. 어느 길이든 마지막에 JSON 파일 1부를 따로 보관하는 것으로 끝납니다.

  1. 예전 버전을 열고 「JSON 백업」을 눌러 파일을 받습니다. 다운로드 폴더에 파일이 실제로 생겼는지 확인합니다.
  2. 새 버전을 열고 오른쪽 위 「불러오기」를 눌러 그 JSON 파일을 고릅니다. (최대 12MB)

주의 — "데이터가 사라졌어요"의 대부분은 이 경우입니다. 새 버전은 같은 PC·같은 브라우저에서 열 때만 예전 작업을 자동으로 보여 줍니다(파일 폴더·이름은 상관없음). 다른 브라우저로 열면 보이지 않습니다. 지워진 것이 아니므로, 원래 쓰던 브라우저에서 예전 버전을 열어 JSON 백업을 받으세요.
반대로 옮길 때 새 버전의 「JSON 백업」 파일(warehouse_project_v2_3_6_날짜.json)은 예전 버전에서도 열립니다. 단, 숫자로 시작하는 열 이름(예: 2A)은 v2.4.1에서 열리지 않고, 「랙 번호 + 높이 활용률」 표시 설정은 예전 버전에서 무시됩니다.

0-4 백업이 어디 있는지 알기

프로그램은 큰 작업 직전에 스스로 백업을 남깁니다. 위치는 두 곳입니다.

「이전 버전·백업」

직전 확인 저장 1개 + 주요 작업(여러 객체 삭제, BEFORE 변경, 복원) 직전의 전체 프로젝트 최신 3개(압축 합계 3.2MB)를 보관합니다. 복원은 확인 1회로 실행됩니다.

「저장소 관리」

저장 크기 측정과 비상 탈출 버튼이 있습니다. 저장이 이상하면 여기서 「현재 메모리 JSON 다운로드」부터 누르세요.

백업 종류언제 생기나보관 개수
전체 프로젝트 백업여러 객체 삭제·BEFORE 변경·복원 직전최신 3개 / 압축 3.2MB
대상별(배치) 백업Excel 적용·BEFORE→AFTER 복제·복원 직전최신 6개 / JSON 3.2MB
날짜별 스냅샷·재고 이력사용자가 저장할 때순환 삭제 없음
새 백업은 저장·확인에 성공했을 때만 가장 오래된 것과 교체됩니다. 실패하면 작업이 취소되고 기존 백업은 그대로 남습니다. 그래도 이 백업들은 이 브라우저 안에만 있으니, 진짜 보관은 JSON 파일입니다.

2-0 Excel 준비와 로케이션 읽기

2-1 Excel 창 열기와 적용 대상 고르기

왼쪽 「Excel / 로케이션 자동 생성」 → 「가져오기 / 자동 배치 설정」을 누릅니다. 맨 위에서 어느 배치에 넣을지부터 고릅니다.

AFTER — 개선 후
새 안을 만들어 볼 때. BEFORE(현재안)는 그대로 남습니다. 처음엔 이것
BEFORE — 개선 전
현재 창고를 기준안으로 만들 때. 바꾸면 기존 AFTER와의 비교 기준도 달라집니다.

2-2 파일 분석 결과 읽기 (1칸)

「파일 선택」 → 「워크시트」 → 「머리글 행」(8) 순서로 확인합니다. 그다음 숫자 세 개만 보면 됩니다.

  1. 「20개 필드 중 ○개 매핑」 — 20이 아니면 「20개 필드 / 수동 열 매핑」을 펼쳐 빠진 열을 직접 고릅니다.
  2. 랙 · 선반 · 품목 수 — 내가 아는 랙 수와 같은지 봅니다.
  3. 「검증 결과 / 오류 원본 행」 — 원본 몇 행이 왜 문제인지 나옵니다. Excel에서 고치고 「데이터 재분석」을 누릅니다.
「사용 면적」 합계가 반복 집계된 경우, 프로그램이 고유 랙 기준으로 다시 계산해 알려 줍니다(예: 59.4㎡ → 9.9㎡).

Excel 「Summary」와 맞는지 대조하기 신규

시트 이름이 「…BE」·「…AF」로 끝나는 호실 시트의 3~4행에 「총 면적 m²」·「면적 사용률 (%)」·「통로 비중 (%)」·「평균 용적률 (%)」·「Rack Q'ty」 요약이 있는 Excel을 고르면, 미리보기에 Excel 값과 앱 계산값을 나란히 보여 주는 상자가 나옵니다. 같은 파일에 「Summary」 시트의 「용적률 80% 미만」 표가 있으면 그 개수도 대조합니다.

실습 정답 「7F-A-3-1-2」 행의 「용적률(%)」 칸에 수식 대신 95%를 직접 입력해 두었습니다(실제 300 ÷ 600 = 50%). 그래서 Excel 평균이 0.7%p 높고, 80% 미만 개수가 하나 적습니다. 이런 "수식 위에 숫자 덮어쓰기"는 자동 감지가 안 되니, Excel에서 용적률 열에 수식이 아닌 칸이 있는지 직접 찾습니다.
대조 결과가 달라도 적용은 막지 않습니다. 적용하면 화면 지표는 앱 계산값을 쓰고, Summary 값은 출처 정보에 참고로만 남습니다. 보고서에는 앱 계산값을 쓰고, 다르면 원인을 함께 적으세요.

「배치 방식」은 5가지입니다. "무엇을 절대 양보할 수 없나?"만 정하면 됩니다.

2-5 로케이션 열 고정 — 추천표 읽는 법

「로케이션 열 고정」을 고르면 「로케이션 열 고정 설정」이 열립니다. 처음에는 「배치 축」을 「자동 추천 (모든 형태 비교)」 그대로 두세요. 프로그램이 8가지 형태를 모두 계산하고, 목표 폭을 충족(✔)하는 형태 중 표의 위쪽(기본형: 한 줄 1열 · 모든 줄 사이 통로)을 고릅니다. 통로가 가장 넓은 형태를 고르는 것이 아닙니다.

설정고를 수 있는 값쉽게 말하면
배치 축자동 추천(기본) / 열 배치(세로) / 행 배치(가로)열을 세로로 세울지 가로로 눕힐지
한 줄 열 수1열 / 2열 (로케이션 순서대로 이어 놓음)한 줄에 열 하나만, 또는 두 열을 이어서
시작 방향첫 랙 위치 설정대로 / 지그재그 (줄마다 반대)모든 줄을 같은 쪽에서 시작할지 번갈아 시작할지
통로 방식모든 줄 사이 통로 / 등 맞댐 쌍 (두 열씩 등을 붙임)두 열의 등을 붙이면 통로가 넓어짐
열 사이 간격남는 폭을 통로에 고르게 나눔 / 통로 목표 폭 그대로남는 공간을 통로에 나눠 줄지
통로 최대 폭(m) 신규기본 1.5통로를 이보다 넓히지 않음. 남는 공간은 끝 벽 쪽 여유로 둠
누락 번호당겨 붙임 (빈자리 없음) / 빈자리 비워 둠 (번호 줄 맞춤)2-6 참고
추천표 한 줄 읽기 (교육용 14×8m · 3열 · 통로 목표 1.20m)
▶ 열 배치(세로) · 한 줄 1열 · 모든 줄 사이 통로6.00m ✔목표 충족 · 기본형 → 자동 선택
열 배치(세로) · 한 줄 1열 · 등 맞댐 쌍11.90m ✔더 넓지만 기본형이 아니라 후순위
행 배치(가로) · 한 줄 2열 · 모든 줄 사이 통로0.60m ✖목표까지 0.60m 부족
열 배치(세로) · 한 줄 2열 · 등 맞댐 쌍불가가장 긴 줄 13.20m > 7.80m
6.00m인데 왜 통로가 1.5m? 추천표의 숫자는 "최대로 넓힐 수 있는 폭"입니다. 실제 적용은 「통로 최대 폭 1.50m 적용: 계산상 6.00m까지 넓힐 수 있지만 상한을 넘는 남는 공간은 끝 벽 쪽 여유로 둡니다」 줄과 「적용: … 통로 1.50m」 줄에서 확인합니다.
기둥·벽·보관 불가 구역·문·보호 통로는 피해서 배치합니다. 공간이 모자라면 ✖ 줄에 「목표까지 길이 0.60m 부족」처럼 얼마가 모자란지 알려 줍니다. 창고가 좁으면(예: 10×6m) 세로 형태가 모두 「불가」가 되고 가로 형태가 자동 선택됩니다.

2-6 빠진 번호 처리 — 당겨 붙임 vs 빈자리 비워 둠

교육용 파일에는 C열 3번 랙이 없습니다. 미리보기에 「누락 번호 1개: C3 → 당겨 붙임(빈자리 없음)」이 표시됩니다.

빈 번호에 실제로 랙을 만들고 싶으면 2칸의 「기록 없는 번호의 랙 후보 생성」을 펼쳐 「1번~최대 등록 번호 사이 누락 랙을 생성」을 켜고 후보 폭·깊이·높이를 입력합니다.

2-7 적용하고 결과 확인

  1. 미리보기 아래 「설정 기준 공간 경고 없음」 또는 위반 목록을 확인합니다. 경고가 있으면 「위반 랙 확인」으로 어떤 랙인지 봅니다.
  2. 경고가 있어도 설계안으로 쓰려면 3칸의 「경고가 발생해도 확인 후 설계안 적용 허용」과 「현재 후보의 경고를 확인했습니다 (실제 설치 승인과 다름)」을 체크합니다.
  3. 「적용 준비 상태」 세 줄이 모두 확인되면 「AFTER에 확인 후 적용」(대상이 BEFORE면 BEFORE)을 누릅니다.
  4. 마지막 확인 창에서 대상과 신규·갱신·제거 수를 한 번 더 확인하고 확인을 누릅니다.
