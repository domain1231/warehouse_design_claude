코스 6

랙 속 자재와 재고 보기 — 선반·색·이름·날짜별 기록

목표 이 코스를 마치면 ① 랙 하나의 선반별 자재를 열어 보고 ② 재고 수량을 넣어 도면 색으로 상태를 읽고 ③ 표시 이름을 현장 용어로 바꾸고 ④ 날짜별 재고를 기록하고 지난 날짜를 조회할 수 있습니다.

약 20분
30초 요약
  1. 랙을 더블클릭하면 「선반별 자재」 창이 열립니다. 막대는 자재 높이 ÷ 선반 높이입니다.
  2. ⑫ 오른쪽에서 「최대 수량」과 「현재 수량」을 넣으면 도면 색이 바뀝니다. Excel의 ROP·MAX Stock은 현재 재고로 들어가지 않습니다. 합계는 「비교」 창 「세부 지표」에서 봅니다.
  3. 「현재 재고·배치 저장」으로 날짜별 기록을 남기면, 날짜를 골라 읽기 전용으로 지난 상태를 볼 수 있습니다.

6-1 랙 상세 — 선반별 자재 열기

  1. Excel로 만든 랙(코스 2)을 도면에서 더블클릭합니다. 「7F-A-1 · 선반별 자재」 창이 열립니다.
  2. 위쪽에 위치·설계/원본 규격·등록 선반·자재 위치·품목 수·출처·기준일이 나옵니다.
  3. 「전체 선반」 목록에서 선반 하나만 고를 수 있고, 카드를 누르면 원본 자재 정보가 오른쪽에 나옵니다.
설정·버튼뜻
「1번 선반이 아래 (사용자 설정)」 / 「1번 선반이 위 (사용자 설정)」Excel에는 선반 방향이 없어 사용자가 현장에 맞게 고름
「논리적 위치」 / 「실측 위치 (미지원)」지금은 로케이션 순서대로 보여 주는 논리적 그림만 지원. 카드 폭은 실제 크기가 아님
높이 막대 색미확인 회색 / 90% 미만 청록 / 90~100% 주황 / 100% 초과 빨강 · 실제 적재율과 별개
「선반 SVG」 · 「선반 PNG」 · 「자재 CSV」이 랙의 그림·자재 목록 내보내기
원본에 현재고가 없으면 상단 「현재 적재율」은 「미확인」입니다. 랙 상세에서 현재고를 추정하지 않습니다.

6-2 재고 수량 넣고 색으로 읽기

  1. 랙을 클릭하고 ⑫ 오른쪽 「최대 수량」·「현재 수량」·「적재 단위」(BOX 등)를 넣습니다.
  2. ⑤ 왼쪽 「Excel / 로케이션 자동 생성」의 「도면 색상 기준」이 「실제 재고 적재율」이면 색이 바로 바뀝니다.
  3. ⑦ 「랙 텍스트」를 「랙 번호 + 실제 적재율」로 바꾸면 랙에 %가 함께 표시됩니다.
합계는 어디서 보나요? 예전 버전의 상단 「수량 기준 적재율 · 단위별」 칸은 이번 버전에서 빠졌습니다. 랙별 값은 ⑫ 선택 정보와 도면 색으로, 배치 전체의 합계는 「비교」 창 「세부 지표」의 「최대 보관 수량 BOX」처럼 단위가 붙은 줄에서 확인합니다(수량을 넣은 랙 수가 「3/3랙 확인」처럼 함께 표시).
「도면 색상 기준」무엇으로 색칠하나
실제 재고 적재율 (기본)현재 수량 ÷ 최대 수량
높이 활용률선반 위 자재 높이 비율 = 비교 창의 「용적률」과 같은 개념 (6-4의 집계 정책으로 랙 하나의 값으로 묶음)
위치 등록 현황Excel 로케이션이 등록된 랙인지
품목별 관리 지표ROP·MAX Stock 같은 품목 관리 기준
BOX·EA·PLT처럼 단위가 다르면 따로 합산합니다. 단위를 비워 두면 「미설정」으로 묶이니 같은 단위로 맞춰 넣으세요.

6-3 도면 표시 바꾸기 — 랙 텍스트·ZONE 이름

⑦ 표시 설정고를 수 있는 값
「랙 텍스트」랙 번호만 / 랙 번호 + 실제 적재율 / 랙 번호 + 높이 활용률 / 상세 정보 / 최소 표시 · 선택 랙
「ZONE·번호 배치」자동 · 좁으면 두 줄 / 항상 두 줄 / 한 줄 / 최소 · 선택 랙
「랙 번호 형식」5 / 05 / 005 (자리수 맞춤)

ZONE 이름을 현장 용어로

  1. A열 랙 하나를 클릭합니다. ⑫ 아래쪽 「ZONE 표시 이름」에 원본 ZONE(A)이 보입니다.
  2. 「현재 배치의 표시 이름」에 원자재를 넣고 「ZONE 이름 적용」을 누릅니다.
  3. 같은 배치·건물·층의 A열 전체가 「원자재 01」, 「원자재 02」…로 표시됩니다. 되돌리려면 「원본 이름 표시」.
표시 이름만 바뀝니다. Excel 식별자와 로케이션은 바뀌지 않으므로 다시 불러와도 같은 랙으로 연결됩니다.

6-4 랙 하나의 높이 값 정하기 — 「랙 높이 집계 정책」

한 랙에는 선반이 여러 개라서 "이 랙의 높이 활용률"을 하나로 묶는 방법을 정해야 합니다. ⑤ 「Excel / 로케이션 자동 생성」에서 고릅니다.

비교 창의 평균 용적률과는 계산이 다릅니다. 이 정책은 도면 표시(색·「랙 번호 + 높이 활용률」)용입니다. 「비교」 창의 「평균 용적률」은 정책과 관계없이 Excel Summary F4 방식(로케이션 평균 → 랙 평균, 빈 랙 제외)으로 계산합니다(M-4).

6-5 색상 설정·기본색 복원

  1. ⑦ 줄의 「색상 설정·기본색 복원」을 누릅니다.
  2. 위쪽에서 화면 색(메인 배경·패널·카드·글자 등 12가지)을 바꾸고 「입력한 UI 색상 적용」.
  3. 원래대로 하려면 「복원 범위」를 고르고 「미리본 기본 색상 복원」.
UI 기본 테마만 복원화면 색만
적재율 기본 색상·기준만 복원⑩ 범례 색과 50%·90% 경계
모든 색상 설정 복원 (양쪽 객체 지정색 포함)전부. 랙마다 따로 칠한 색도 지워짐
적재율 색 경계(기본 50%·90%)와 색은 ⑤ 「05 / 적재율 색상」에서 바꿉니다.

6-6 날짜별 재고 기록과 지난 날짜 조회

  1. ⑧ 「하단 전체 펼치기」 → 「▸ 재고기록」을 펼칩니다.
  2. 저장 날짜·데이터 출처를 확인하고 「현재 재고·배치 저장」을 누릅니다. 「배치 이력 함께 저장」을 켜 두면 그날 배치도 같이 남습니다.
    2026-11-16 기록을 저장했습니다. 미입력 재고는 미확인으로 유지됩니다.
  3. 지난 날짜를 보려면 위쪽 날짜를 고릅니다. 화면이 읽기 전용으로 바뀝니다.
    2026-11-16 · 읽기 전용 · 기록 없음 · 해당 날짜 저장 배치
  4. 다 봤으면 「현재 편집으로」를 눌러 돌아옵니다.
조회 방식보이는 것
「해당 날짜 배치 우선」그날 저장한 배치와 그날 재고
「현재 배치 + 과거 재고」지금 배치에 그날 재고 숫자만 얹어 봄
재고를 한꺼번에 넣을 때는 「재고 CSV 가져오기」를 씁니다. 「CSV 양식」을 받아 date, rackId, capacity, quantity, unit, source(한국어 머리글 날짜/랙ID/최대수량/현재수량/단위/출처도 가능)를 채웁니다. rackId는 바뀌지 않는 내부 ID이므로 양식에 있는 ID를 그대로 쓰세요. 가져오기는 이력에만 들어가고 현재 수량은 자동으로 바꾸지 않습니다.
