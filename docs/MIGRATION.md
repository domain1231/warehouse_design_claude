# v2.4.1 → 재구축본 이전 안내

## 데이터 위치 (같은 브라우저, 같은 주소 기준)

| | 키 | 비고 |
|---|---|---|
| v2.4.1 | `warehouse-studio-v1` | 재구축본은 읽기만 하고 쓰지 않습니다 (D-006) |
| 재구축본 프로젝트 | `warehouse-layout-v2:slot-a`, `slot-b`, `pointer` | 2-슬롯 + 포인터, 쓰기 후 읽기 확인 (D-007) |
| 재구축본 전체 백업 | `warehouse-layout-v2:project-backups` | 최신 3개·압축 합계 3.2MB (D-026) |
| 재구축본 휠 감도 | `warehouse-layout-v2:wheel-sensitivity` | v2.4.1 설정은 처음에 읽기만 |

배치 백업(BEFORE·AFTER 합계 최대 6개·3.2MB)은 프로젝트 JSON 안에 들어 있어 프로젝트와 함께 저장·내보내집니다.

## 처음 열 때

재구축본에 저장본이 없으면 v2.4.1 저장 데이터를 읽어 표시하고 아래 안내를 보여줍니다.

> 기준본(v2.4.1) 저장 데이터를 불러왔습니다. 저장하면 새 저장 영역에 기록하며 기준본 데이터는 그대로 둡니다.

저장하기 전까지 상태는 "저장 안 됨"입니다. 저장해도 v2.4.1 데이터는 수정·삭제되지 않습니다. 다른 주소(파일 경로·도메인)에서 열면 브라우저 저장소가 달라 이 데이터가 보이지 않습니다. 그 경우 아래 JSON 방식을 쓰세요.

## 데이터를 명시적으로 옮기기

1. v2.4.1에서 JSON 백업(내보내기)으로 파일을 보관합니다.
2. 재구축본에서 'JSON 불러오기'로 파일을 선택합니다 (12MB 제한). 현재 프로젝트는 먼저 자동 백업되고 교체는 실행취소할 수 있습니다.

## v2.4.1로 되돌아가기

- v2.4.1 데이터는 재구축본이 건드리지 않으므로 그대로 열립니다. 단, 재구축본에서 한 작업은 v2.4.1에 없습니다.
- 재구축본의 최신 작업을 옮기려면 재구축본에서 JSON을 내보내 v2.4.1에서 불러옵니다. 내보내기는 스키마 2.3.6입니다 (파일명 `warehouse_project_v2_3_6_<날짜>.json`, D-028).
- 검증 범위: 재구축본이 저장하는 압축 원문을 v2.4.1이 읽는다는 것은 `tools/legacy-compat.mjs`로, 재구축본이 내보낸 JSON 파일을 v2.4.1의 'JSON 불러오기'로 열어 교체·저장(SAVED)까지 되는 것은 `tools/legacy-json-compat.mjs`로 확인했습니다(가상 프로젝트, 2026-11-15 PASS). 실제 운영 JSON은 사용자 PC에서 확인이 필요합니다.

## 백업

- 프로젝트 백업 링: 객체 2개 이상 삭제·BEFORE 변경·복원 직전에 자동 생성. '이전 버전·백업'에서 복원(현재 상태를 먼저 백업) (D-026).
- 배치 백업: Excel 적용·BEFORE→AFTER 복제·복원 직전에 생성 (D-024).
- 중요한 작업 전에는 JSON을 내보내 별도 보관하세요. '저장소 관리'에서 현재 JSON·복구 JSON을 내려받을 수 있습니다.

## 알려진 차이

| 항목 | 차이 | 근거 |
|---|---|---|
| Excel 적용 | 저장 실패 시 전체 취소 대신 편집을 메모리에 유지하고 저장 실패를 표시, 실행취소 가능 | D-018 |
| 열 우선 자동 배치 | 시간 상한(1.5초) 없이 탐색 횟수로만 종료. 매우 큰 배치에서 결과가 다를 수 있음 | D-023 |
| BEFORE→AFTER 복제 | 배치 백업 한도는 BEFORE·AFTER 합계(문구 수정). 재고 기록 복사는 기준본과 같음 | D-024 |
| 백업·저장 | 복원 확인 1회, 보호 원본 키 대신 손상 저장본을 덮어쓰지 않는 방식 | D-026 |
| 내보내기·패널 | 랙 `<title>`이 전체 이름, 방위 표시 추가, 하단 패널 한 줄 4구역 | D-028 |
| 창고 치수·참고 도면 | 회전 소수 각도 허용, 가져온 JSON 이미지 문자열 이스케이프 강화 | D-029 |
| 거리 표시 | 화면 이동 중 다음 다시 그리기 전까지 거리 표시가 남음 | D-030 |
