## 원인과 수정
- 랙 선택마다 오른쪽·상단 공간 지표를 다시 그리며 Track C 공간 구성(랙 > 보관 불가 > 통로 > 잔여 누적 합집합)과 기존 metrics의 면적 합집합을 두 시나리오에서 계산한다. 내용 기준 LRU 캐시(`AREA_CACHE`)가 16칸이라 한 번 그리기에 필요한 키 수(시나리오당 약 6개 × 2 + 기존 3개)를 넘어 계속 밀려났다(캐시 thrash).
- `AREA_CACHE_MAX` 16 → 64. 캐시 키는 도형 내용이라 제자리 수정에도 오래된 값을 돌려주지 않는다(단위 검사 `tests/unit/metrics-cache.test.js`). 계산 값 변화 없음, 골든 불변.
- 끌기·확대·저장은 수정 전후 차이가 측정 편차 범위.
