# AI 모델 사용 기준

2026-11-11 사용자 확정. 명세서 30장(Codex GPT-6.1 SOL Medium/High 기준)을 Claude 개발에 맞게 대응시킨 정책이다.

| 명세서 등급 | 작업 | Claude 모델 |
|---|---|---|
| Medium | UI·CSS, 문서, 기존 예시를 따르는 테스트, 빌드·배포 스크립트, 릴리스 노트 | Sonnet 계열 작업자 |
| Medium (탐색) | 파일·사용처 찾기, 단일 파일 요약 | Haiku 계열 작업자 |
| High | 정밀 기하·충돌, 자동 배치 탐색, 저장 트랜잭션·복구, 스키마 마이그레이션, 복합 상태 오류, 고위험 구조 변경 | 메인 세션(Opus) |
| 상한 | 최상위 모델(Fable 계열) | 기본 사용하지 않음. 대형 독립 리뷰가 필요할 때만 사용자 동의 후 사용 |

## 판단 기준
실수했을 때 테스트가 바로 잡아내는 작업은 Sonnet에 맡긴다. 테스트를 통과하면서 특정 경계값에서만 데이터가 틀릴 수 있는 작업은 Opus가 맡는다.

## 운영
- Sonnet 결과가 검사에서 실패하면 Opus가 이어받는다(재시도 1회).
- Phase 3(CAD)처럼 상호작용이 까다로운 영역은 Sonnet 구현 + Opus 검토.
- 세션별 사용량은 초기 몇 세션 실측 후 이 문서에 기록하고 배분을 다시 판단한다. 실측 없이 절감률을 주장하지 않는다.
- 기준본 저장소의 `tools/ai-task.cjs`(Codex SOL 라우팅)는 Codex 병행 사용을 위해 기준본에 그대로 둔다.
