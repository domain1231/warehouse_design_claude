# 정식 판(v2.5.0) 게시 전 확인 목록

자동 검사로 확인할 수 없는 항목을 사람이 직접 확인한다. 모든 항목이 PASS여야 정식 판(pre-release 아님)을 게시한다.
결과는 이 표를 복사해 Release 본문 또는 Issue에 적는다. 업무 Excel·운영 JSON은 저장소에 올리지 않는다.

## 0. 준비
- 대상 파일: Release에 첨부된 `warehouse_layout_designer_v2_5_0-*.html` (sha256을 Release 본문과 대조)
- 환경: Windows + Microsoft Edge 최신, 실제 마우스와 노트북 터치패드
- 자료: 실제 업무 Excel 전체 파일(모든 시트), 기존 v2.4.1에서 저장한 운영 JSON 1개 이상

## 1. 실사용 흐름 (Windows Edge · 실제 마우스)
| # | 확인 | 방법 | 결과 |
|---|---|---|---|
| 1-1 | 열기 | 파일을 더블클릭해 오프라인으로 열림, 인터넷 끊고도 동작 | ☐ |
| 1-2 | 도면 조작 | 휠 확대·축소, 가운데 버튼/스페이스 끌기 이동, 랙 클릭·끌기 이동 | ☐ |
| 1-3 | 터치패드 | 두 손가락 스크롤·핀치 확대, 끌기 이동이 의도대로 동작 | ☐ |
| 1-4 | 정밀 입력 | 오른쪽 패널 X·Y·폭·깊이에 0.001m 단위 입력 → 도면 반영 | ☐ |
| 1-5 | 삭제·되돌리기 | 랙 2개 이상 삭제 시 확인 창 → 삭제 → ↶로 복구 | ☐ |
| 1-6 | 저장 | Ctrl+S → "저장됨 (SAVED)" 알림, 새로고침 후 그대로 | ☐ |
