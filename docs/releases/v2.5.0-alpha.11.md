## Warehouse Layout Designer v2.5.0-alpha.11 (시험판 · pre-release)

alpha.10 이후 **Track C — 공간지표·BEFORE/AFTER 비교 재설계**를 모두 반영한 시험판입니다. 지표 정의를 업무 Excel Summary 산식과 맞췄고, 비교 화면을 공간 효율 개선을 보여 주는 구성으로 바꿨습니다. 프로젝트 데이터 스키마 **2.3.6** 호환은 그대로입니다.

### 지표를 Excel Summary 산식과 일치 (D-060·D-061)
- 모든 화면 지표의 출처를 `src/metrics/space.js` 하나로 모았습니다.
- **평균 용적률** = Excel F4 방식(로케이션 용적률 → 랙별 평균 → 랙 평균). 기존 '선반 가중' 값은 보조로 함께 표시.
- **면적 사용률·통로 비중**은 ① Excel 방식이 기본: 총면적 = Excel 입력값(C4, 없으면 도면 전체), 통로 비중 = 1 − 면적 사용률. 도면 통로 면적 기준 값은 보조 표시.
- Excel 적용 시 총면적(referenceArea)을 출처 정보에 저장. 예전 데이터는 '기존 랙 정보만 업데이트'를 한 번 실행하면 기록됩니다.
- 오른쪽 공간 지표: 80% 미만 로케이션, 빈 랙·저활용 랙, 유휴 공간 랙, 공간 구성(합계 100%), BEFORE→AFTER 증감.

### BEFORE/AFTER 비교 화면 (D-062~D-064)
- **목적 지표 표**: 평균 용적률 → 80% 미만 로케이션 → 빈 랙 → 저활용 랙 → 통로 비중 → 공간 구성 → 최소 통로 폭. 행마다 산식 툴팁. 공간 구성 100% 누적 막대, 배치 변경 한 줄 요약.
- **Δ 용적률 지도(기본 보기)**: 한 장의 도면에서 랙을 용적률 변화(%p)로 칠함(+40 이상 / +20~40 / +1~20 / 변화 없음 / 악화 빗금 / 미확인 / 신규). 이동·회전·규격 변경은 노랑 점선만. 기존 좌우 비교는 보조 보기.
- **랙 변화 목록**: 좌표 표 대신 Δ 큰 순 목록, 개선/악화/변화 없음/기타 필터, '랙 변화 목록 CSV'. 기존 '랙 변경 CSV'는 그대로.
- 한쪽 배치가 비어 있으면 '배치 없음'으로 표시.

### 통로·벽 이격 검사 (D-065·D-067)
- 통로 판정 기준 = max(통로 최소 확보 폭, 왼쪽 '통로 종류 기준'). 종류 기준은 사용자가 언제든 수정.
- 주통로 기준이 1.0m 미만이면 설정 경고(저장은 막지 않음). '최소 통로 폭' 칸은 기준 미달 시 경고 색.
- '03 / 정밀 배치'의 벽 최소 이격을 모든 배치(직접 그린 도면 포함)에서 바로 수정·즉시 재검사.

### Excel 불러오기 Summary 대조 (D-068)
- 미리보기에서 호실 시트 Summary(F4·D4·E4·G4·H4)와 앱 계산을 나란히 비교, 다르면 원인 자동 감지: 용적률 수식 분모 열 오류 · 형식 밖 로케이션 · 자재높이 > 단 높이 · Summary 표 범위 밖 행 · 직접 입력값 · 단 높이 0. '차이 행 CSV'. 적용은 막지 않으며 Summary 값은 참고로 저장.

### 성능
- 500랙 랙 선택 약 60ms(수정 전 106ms), 끌기 프레임 약 47ms, 편집 1회 저장 약 350ms.
