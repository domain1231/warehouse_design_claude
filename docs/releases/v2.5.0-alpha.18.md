## Warehouse Layout Designer v2.5.0-alpha.18 (시험판 · pre-release)

alpha.17 이후 **기준일 스냅샷 차분 저장(D-094)**을 반영한 시험판입니다. 지표 산식·배치 계산·화면 구성은 바뀌지 않았습니다. 프로젝트 데이터 스키마 **2.3.6** 파일 읽기 호환은 그대로입니다.

### 저장 파일이 훨씬 작아집니다
- 배치 스냅샷·Excel 스냅샷을 기준일마다 통째로 쓰지 않고, **직전 기준일과 달라진 부분만** 저장합니다(10개마다 전체 스냅샷 1개).
- 앱 안의 동작(이력 보기·비교·복원·검증)은 그대로입니다. 저장 직전에 되돌려 원래와 같을 때만 줄여 씁니다.
- 가상 사용 시나리오(가져오기 30·배치 저장 30·자동 배치 10): 작은 JSON **23.56MB → 4.88MB**. 크기 예산 8MB 검사를 CI 고정 검사로 바꿨습니다.

### ⚠ 이전 버전 앱에서 열 때
- 작은·읽기 쉬운 JSON은 **v2.4.1과 alpha.17 이전 시험판에서 열리지 않습니다**("배치 형식 또는 객체 수가 올바르지 않습니다", 열려 있던 작업은 유지).
- 이전 앱에서 열 파일은 **저장소 관리 → JSON 저장 형식 → '기준본 호환 JSON'**으로 저장하세요(이력을 모두 펼친 이전과 같은 원문 — v2.4.1에서 열림·백업 복원 확인).
- 같은 브라우저에서 이전 시험판을 열면 브라우저 저장본을 읽지 못합니다(보호 원본은 유지). 이전 시험판으로 돌아가기 전에 '기준본 호환 JSON'을 받아 두세요.

### 이력 정리 보완
- 정리할 때 남긴 자동 배치 확인 이력이 가리키는 기준일 스냅샷도 함께 남깁니다(차분 저장이라 비용이 작음).
