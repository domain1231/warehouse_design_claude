## Warehouse Layout Designer v2.5.0-alpha.7 (시험판 · pre-release)

alpha.3 이후의 수정과 **자동 배치 기준 배치 후 수정**·**지표 영역 접기** 기능을 담은 시험판입니다. 게시되지 않은 alpha.4·alpha.5·alpha.6의 내용이 모두 들어 있습니다. 프로젝트 데이터 스키마 **2.3.6** 호환은 그대로입니다.

### 새 기능
- **자동 배치 기준을 배치 후 수정 (D-054)**: 왼쪽 '정밀 배치 설정'의 '랙 사이 최소 여유' 아래에서 **열 사이 간격·랙 사이 간격·벽 최소 이격·통로 목표 폭**을 Excel 자동 배치 후에도 고칠 수 있습니다. 랙은 움직이지 않고 간격·이격 검사 기준만 바뀝니다. 0~50m, 0.001m 단위, 실행취소 가능. 자동 배치 기준이 없는 배치(샘플·수동 작성)에서는 비활성입니다. v2.4.1에 없는 화면 요소입니다(사용자 승인).

- **상단 지표 영역·공간 지표 접기 (D-055)**: 저장 상태 줄 오른쪽 '지표 접기'로 안내 배너·지표 카드·검사 요약 줄을 접고, 한 줄 요약(`59랙 · 점유율 36.7% · 공간 경고 6건`)만 남깁니다. 경고 수는 접어도 보입니다. 1920×1080에서 도면 작업 영역이 약 165px 위로 올라와 스크롤이 줄어듭니다(세로 1400px 이상 화면에서는 도면 칸 자체가 커집니다). 오른쪽 '공간 지표' 제목을 눌러 지표 표만 접을 수도 있습니다. 접은 상태는 새로고침 후에도 유지됩니다. v2.4.1에 없는 화면 요소입니다(사용자 승인).

- **하단 패널을 열어도 도면 칸 유지 (D-056)**: 하단 패널(재고기록·배치이력·랙 목록·공간검토)을 열면 도면 칸이 약 268px까지 줄던 것을, 닫았을 때와 같은 최소 높이로 유지합니다(1920×1080: 268 → 약 757px). 하단 패널은 도면 아래에 원래 높이로 놓이고 페이지를 아래로 스크롤해서 봅니다. v2.4.1과 다른 동작입니다(사용자 승인).

### 수정
- **창고 치수 1mm 단위 입력 (D-052)**: 창고 가로·세로·천장 높이를 0.001m 단위로 입력할 수 있습니다(실측 18.44m 등). Excel 불러오기 창의 창고 가로·세로도 같은 단위입니다.
- **샘플 구조물이 Excel 자동 배치에 남던 문제 (D-053)**: 창고 치수를 적용하거나 모든 객체를 지우면 '샘플 배치' 표시가 해제되어, Excel 자동 배치가 예전 기둥·통로를 유지하지 않습니다. 유지하는 구조물이 새 창고 범위 밖이면 경고가 나옵니다.
- **자동 배치 기준 입력 복귀**: 기준 입력이 거부되면(빈 값·범위·단위·BEFORE 잠금) 입력란이 저장된 값으로 돌아옵니다. 전에는 잘못 넣은 값이 남아 실제 기준과 달라 보였습니다.
- **도면 칸 최소 높이 (D-051)**: 낮은 화면에서 도면 칸이 v2.4.1 높이(약 674px) 아래로 줄지 않습니다(1920×890: alpha.3 277px → 674px).

### 그 밖의 내용
- alpha.3의 모든 기능(구조물 반영 자동 추천, 로케이션 형식 확장, 통로 최대 폭 상한 등)을 그대로 포함합니다.
- 주의: `2A`처럼 숫자로 시작하는 열, 또는 0.1m 단위가 아닌 창고 치수(예: 18.44m)가 들어간 프로젝트 JSON은 v2.4.1에서 열리지 않거나 치수 적용이 막힐 수 있습니다.
