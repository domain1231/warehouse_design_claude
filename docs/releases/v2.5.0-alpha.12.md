## Warehouse Layout Designer v2.5.0-alpha.12 (시험판 · pre-release)

alpha.11 이후 **Phase 11(동등성·성능 검증)** 결과와 독립 검토 수정을 반영한 시험판입니다. **운영 JSON 호환 확인(11-5)용**으로 배포합니다. 프로젝트 데이터 스키마 **2.3.6** 호환은 그대로입니다.

### 저장·데이터 보호 (독립 검토 반영)
- 손상된 저장본을 교체하다 저장 공간 부족으로 한 번 실패해도 다시 저장할 수 있습니다(이전에는 이후 저장이 계속 막힘).
- 저장하는 동안 들어온 편집이 'SAVED'로 표시되지 않습니다.
- 저장이 실패해도 편집 직전 자동 백업이 지워지지 않습니다.
- 백업 묶음이 손상되면 따로 격리 보관하고 새로 시작합니다(큰 편집이 막히지 않음).
- BEFORE가 잠겨 있으면 BEFORE를 바꾸는 실행취소/다시 실행을 거부합니다(v2.4.1과 같은 규칙·문구).

### Excel·자동 배치
- **Excel '업데이트'·'병합'에서 사용자 수정값 보존(D-070)**: 블록(ZONE)·랙 종류·사용자 지정 속성·메모·용량·수량·단위는 그대로 두고 Excel 유래 값(로케이션·선반·자재·원본 규격, 정책에 따른 설계 규격·위치)만 갱신합니다. v2.4.1은 일부 값을 기본값으로 되돌렸습니다.
- 고정 열 자동 배치의 장애물 회피가 '위치 유지'·잠금 랙을 밀지 않습니다.
- Excel 불러오기 Summary 대조에 'Summary' 시트의 '용적률 80% 미만' 값 추가(D-069).

### 편집 조작 (D-071·D-072)
- **방향키로 화면 이동**: 아무것도 선택하지 않았을 때 방향키로 도면 화면을 이동합니다. 도면은 누른 방향으로 움직입니다(Shift 3배, 두 키를 함께 누르면 대각선, 누르고 있는 동안 연속). 선택이 있으면 기존처럼 객체를 미세 이동하고, 두 키를 함께 누르면 대각선으로 한 번에 이동합니다. 입력칸·대화상자에서는 동작하지 않으며, '창고 중심 고정 확대'가 켜져 있으면 마우스로 끌 때처럼 고정을 풀고 이동합니다.
- **영역 선택 '모든 객체'**: '영역 선택 기준'에 '일부 겹침 · 모든 객체', '완전 포함 · 모든 객체'를 추가했습니다(기본은 랙만). 여러 종류를 함께 선택하면 이동·삭제는 전체, 회전·복제·그룹 편집은 랙만 적용하고, 삭제 확인 창에 종류별 개수를 보여 줍니다.

### 성능
- 랙 선택 시 공간 지표 재계산 생략. v2.4.1 대비(500랙): 선택 524→44ms, 끌기 183→46ms, 확대 324→34ms, 저장 506→339ms, 메모리 11.8→7.3MB. 실행취소 기록 메모리는 약 20MB에서 더 늘지 않음(v2.4.1 112MB).
