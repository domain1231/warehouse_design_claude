## Warehouse Layout Designer v2.5.0-alpha.10 (시험판 · pre-release)

alpha.9 이후 공간 지표를 정리한 시험판입니다. 프로젝트 데이터 스키마 **2.3.6** 호환은 그대로입니다.

### 상단 지표 (5칸 → 8칸)
전체 창고 면적 · 현재 랙 수 · 랙 면적 점유율 · **통로 비중** · **보관 불가 구역 비중** · **보관 가능 잔여 비중** · **최소 통로 폭** · 공간 경고

- **통로 비중 (D-058)**: 통로·작업 구역 면적 ÷ 전체 창고 면적. 아래에 면적(㎡).
- **보관 불가 구역 비중 (D-058)**: 벽·기둥·보관 금지·문 안전 구역 면적 ÷ 전체 창고 면적. 아래에 면적(㎡).
- **보관 가능 잔여 비중 (D-059)**: 어떤 객체도 차지하지 않은 면적 ÷ 전체 창고 면적. 랙을 더 놓을 수 있는 여유의 상한.
- **최소 통로 폭 (D-059)**: 통로마다 계산한 유효 폭 중 가장 좁은 값. 아래에 통로 코드·목표 폭, 목표에 못 미치면 ⚠.
- 면적은 오른쪽 '공간 지표'와 같은 값입니다(창고 안쪽만, 겹치는 부분은 한 번만).
- '수량 기준 적재율 · 단위별' 칸은 상단에서 뺐습니다. 랙별 적재율은 선택 정보·랙 목록에 그대로 있습니다.

### 오른쪽 '공간 지표'에 5줄 추가 (D-059)
- 보관 가능 잔여 비중
- 통로 : 랙 면적비 (통로·작업 구역 ÷ 랙 면적 합계)
- 최소 통로 폭
- BEFORE→AFTER 증감 (랙 수 · 랙 면적 점유율 %p · 통로 비중 %p). 한쪽 배치가 비어 있으면 그렇게 표시합니다.
- **평균 용적률**: 랙별 높이 활용률(Excel 자재 높이 ÷ 선반 높이)의 평균, 값이 있는 랙만, 'n/N랙 확인' 표시. 업무 Excel의 '용적률(%)'과 같은 뜻이며 현재고가 아닙니다.
