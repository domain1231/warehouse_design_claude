## Warehouse Layout Designer v2.5.0-alpha.14 (시험판 · pre-release)

alpha.13 이후 **Track D(BE/AF 비교 화면 가독성, D1~D7)**와 편집·백업 표시 개선을 반영한 시험판입니다. 지표 산식(Track C)은 바뀌지 않았고 표시만 바뀌었습니다. 프로젝트 데이터 스키마 **2.3.6** 호환은 그대로입니다(새 선택 필드 `settings.compareView`는 v2.4.1이 무시).

### 비교 화면 — 한눈에 읽기 (D1·D4·D5·D6)
- **결론 문장**: 맨 위에 개선된 목적 지표를 최대 3개(평균 용적률 → 빈 랙 → 보관 가능 합계 순) 한 줄로. 악화 지표는 '⚠ 주의'로 따로.
- **KPI 카드 4개**: 평균 용적률 · 80% 미만 로케이션 · 빈 랙 · 보관 가능 합계 (BEFORE → AFTER, 차이).
- **방향 색**: 개선 초록 ▲ · 악화 빨강 ▼ · 변화 없음 회색 —. 색과 함께 화살표·'개선/악화' 문구 표시. 통로 비중·공간 구성·선반 여유 용적은 방향이 정해지지 않아 색 없음.
- **비교표**: `지표 · BEFORE → AFTER · 차이` 3열 한 줄, 변화 0 행은 흐리게.
- **공간 구성 막대**: 4% 이상 구간은 막대 안에 비율, 두 막대 사이에 구간별 Δ, 바뀐 구간만 노란 강조.
- **출처 칩**: 출처 두 줄을 `BEFORE 시트·기준일` / `AFTER 시트·기준일` / `면적 기준` 칩 한 줄로(파일명·가져온 시각은 마우스를 올리면 표시). 면적 적용 버튼은 `AFTER 면적 N㎡ 적용`.

### Δ 지도·배치 (D2·D3·D7)
- **발표 모드**: 통로 이름·치수·구조물 이름·랙 태그를 숨기고 Δ 값을 랙 칸에 맞춰 크게(라벨 겹침 없음). **열 단위 요약**: 열마다 랙 용적률 평균의 Δ 하나. 설정은 프로젝트에 저장.
- **범례 고정**: 지도 위에 고정, `? Excel 미연결` 항상 표시.
- **2단 배치**: 1280px 이상 화면은 왼쪽 표·막대, 오른쪽 지도 고정. 1366×768에서도 결론·KPI·지도가 스크롤 없이 보임.
- **표·지도 연동**: 비교표의 평균 용적률·80% 미만·빈 랙·저활용 랙·보관 가능 합계 행, 랙 변화 목록 행을 누르면 지도에서 그 랙만 강조. 다시 누르거나 Esc로 해제, Enter로도 동작.
- **발표용 PNG / PDF**: A4 가로 한 장(결론·KPI·목적 지표·공간 구성·Δ 지도·각주). 오프라인에서 생성.

### 편집·저장 표시 (D-076·D-077)
- 정밀 입력(X·Y·폭·깊이)이 공간 검증으로 전체 취소되면 되돌아간 칸을 표시합니다.
- 백업·가져오기 시각을 한국 시각으로 표시합니다.

### 확인 부탁
- 706호 BE/AF Excel로 결론 문장(로드맵 예시: 평균 용적률 +26.4%p, 빈 랙 12대, 보관 가능 공간 +6.1%p)과 KPI·막대 확인.
- 발표용 PDF를 실제로 인쇄했을 때 글자 크기·색.
- Windows Edge, 실제 마우스(표 행 클릭·키보드 Enter/Esc).
