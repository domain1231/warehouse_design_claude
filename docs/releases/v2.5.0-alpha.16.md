## Warehouse Layout Designer v2.5.0-alpha.16 (시험판 · pre-release)

alpha.15 이후 **Track E E1·E2(프로젝트 파일 크기·불러오기 상한)**를 반영한 시험판입니다. 지표 산식과 화면 배치는 바뀌지 않았습니다. 프로젝트 데이터 스키마 **2.3.6** 호환은 그대로입니다. alpha.15의 Track D 내용도 모두 들어 있습니다.

### 큰 프로젝트 파일 불러오기 (E1 · D-086)
- **불러오기 상한 12MB → 24MB**: 앱이 저장한 12MB 초과 JSON을 같은 앱이 열지 못하던 문제를 고쳤습니다. 상한은 압축 백업과 같은 값 하나(24MB)입니다.
- **ZIP·압축 백업도 열기**: `JSON 불러오기`에서 `project.json`이 든 ZIP 파일과 압축 백업 JSON(예: 보호 원본 내려받기 파일)도 선택할 수 있습니다.
- **저장 크기 안내**: JSON 파일이 12MB(상한의 50%)를 넘으면 경고, 24MB를 넘으면 "다시 열 수 없음 · 이력 정리 후 저장" 안내가 나옵니다. 내려받기는 막지 않습니다.

### 작은 JSON 저장 (E2 · D-087)
- **저장소 관리 → JSON 저장 형식**: `작은 JSON(들여쓰기 없음)`(기본) / `읽기 쉬운 JSON(들여쓰기)`. 내용은 같고 공백만 다릅니다.
- 작은 JSON은 약 절반 크기입니다(운영 자료 기준 −51~53%). JSON 백업·이전 버전 JSON·비교 중 JSON 저장에 적용됩니다.
- 선택은 이 브라우저에 기억되며 프로젝트 파일에는 넣지 않습니다.

### 확인 부탁
- 열리지 않던 `warehouse_project_v2_3_6_2026-11-25.json`(13.37MB)을 그대로 불러오기.
- `JSON 백업`으로 다시 저장 → 파일이 약 6MB인지, 다시 불러와 비교 화면 결론 문장이 같은지.
- 저장소 관리에서 `읽기 쉬운 JSON`으로 바꿔 저장하면 12MB 초과 경고가 나오는지.
- Windows Edge에서 위 항목.
