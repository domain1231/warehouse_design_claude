## Warehouse Layout Designer v2.5.0-alpha.8 (시험판 · pre-release)

alpha.7 이후 보고된 문제를 고친 시험판입니다. 프로젝트 데이터 스키마 **2.3.6** 호환은 그대로입니다.

### 수정
- **예전 배치에서도 자동 배치 기준 편집 (D-057)**: 왼쪽 '정밀 배치'의 열 사이 간격·랙 사이 간격·벽 최소 이격·통로 목표 폭(D-054)이 예전에 Excel을 적용해 만든 배치나 그 JSON을 불러온 배치에서는 꺼져 있었습니다. 배치에 기준 기록이 없고 Excel 입력값이 프로젝트에만 저장되어 있었기 때문입니다.
  - 이제 Excel 불러오기 이력이 있으면 입력란이 켜지고, Excel 입력값을 '현재 배치에는 미적용' 안내와 함께 보여줍니다.
  - 값을 고치면 지금 보고 있는 배치(BEFORE 또는 AFTER)에만 적용됩니다. 고친 값 외의 칸은 Excel 입력값으로 채워지고, 이때부터 랙·열 간격 검사가 켜집니다(Excel 자동 배치를 다시 적용했을 때와 같은 결과).
  - 랙은 움직이지 않습니다. 이 입력란은 랙별이 아니라 배치 전체 기준입니다.
  - Excel 불러오기 이력이 없는 배치(샘플·직접 작성)는 지금처럼 비활성입니다.

### 그 밖의 내용
- alpha.7의 모든 기능(자동 배치 기준 배치 후 수정, 지표 영역 접기, 하단 패널 열림 시 도면 칸 유지, 창고 치수 1mm 입력 등)을 그대로 포함합니다.
