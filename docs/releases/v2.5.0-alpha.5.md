## Warehouse Layout Designer v2.5.0-alpha.5 (시험판 · pre-release)

실측 창고 작업에서 보고된 문제를 고친 시험판입니다. 게시되지 않은 alpha.4의 수정(도면 칸 최소 높이)도 함께 들어 있습니다. 프로젝트 데이터 스키마 **2.3.6** 호환은 그대로입니다.

### 수정
- **창고 치수 1mm 단위 입력 (D-052)**: 창고 가로·세로가 0.1m 단위만 받아 실측 18.44m를 넣으면 '치수 적용'이 꺼졌습니다. 이제 가로·세로·천장 높이를 **0.001m(1mm) 단위**로 입력할 수 있습니다(범위 1~500m 그대로). v2.4.1은 0.1m 단위만 받습니다.
- **샘플 구조물이 Excel 자동 배치에 남던 문제 (D-053)**: 창고를 다시 만들거나 객체를 모두 지운 뒤에도 '샘플 배치' 표시가 남아, Excel 자동 배치가 예전 기둥·통로를 유지했습니다. 이제 창고 치수를 적용하거나 모든 객체를 지우면 샘플 표시가 해제됩니다. 또 유지하는 구조물이 새 창고 범위 밖에 있으면 Excel 대화상자에 "⚠ 유지한 구조물 n개가 새 창고 범위 밖에 있습니다…" 경고가 나옵니다.
- **도면 칸 최소 높이 (D-051, alpha.4 내용)**: 낮은 화면에서 도면 칸이 작게 줄던 문제를 고쳤습니다. 도면 칸은 v2.4.1 높이(약 674px) 아래로 줄지 않습니다(1920×890: alpha.3 277px → 674px).

### 그 밖의 내용
- alpha.3의 모든 기능(구조물 반영 자동 추천, 로케이션 형식 확장, 통로 최대 폭 상한 등)을 그대로 포함합니다.
- 주의(alpha.3과 같음): `2A`처럼 숫자로 시작하는 열, 또는 0.1m 단위가 아닌 창고 치수(예: 18.44m)가 들어간 프로젝트 JSON은 v2.4.1에서 열리지 않거나 치수 적용이 막힐 수 있습니다.
