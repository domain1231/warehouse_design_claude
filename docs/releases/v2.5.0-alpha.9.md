## Warehouse Layout Designer v2.5.0-alpha.9 (시험판 · pre-release)

alpha.8 이후 보고된 문제를 고친 시험판입니다. 프로젝트 데이터 스키마 **2.3.6** 호환은 그대로입니다.

### 수정
- **JSON 불러오기 중 'The operation was aborted' 대응**: Windows에서 JSON을 불러올 때 브라우저가 파일 읽기를 중단하면 이 오류가 났습니다. 클라우드 동기화 폴더(OneDrive 등)의 온라인 전용 파일, 네트워크 드라이브, 내려받는 중이거나 다른 프로그램이 쓰는 중인 파일에서 생길 수 있습니다.
  - 이제 읽기가 중단되면 다른 방식으로 한 번 더 자동으로 읽습니다.
  - 그래도 실패하면 `파일 처리 실패: … (읽기 단계 · AbortError) — 파일을 바탕화면 같은 로컬 폴더로 복사한 뒤 다시 선택하세요…` 안내가 나오고, 현재 프로젝트는 그대로 유지됩니다.
  - 그 밖의 불러오기 오류 문구는 v2.4.1과 같습니다.

### 그 밖의 내용
- alpha.8의 모든 기능(예전 배치에서도 자동 배치 기준 편집, 지표 영역 접기, 하단 패널 열림 시 도면 칸 유지, 창고 치수 1mm 입력 등)을 그대로 포함합니다.
