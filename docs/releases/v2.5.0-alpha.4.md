## Warehouse Layout Designer v2.5.0-alpha.4 (시험판 · pre-release)

v2.5.0-alpha.3에서 **낮은 화면에서 도면 칸이 작게 보이던 문제**를 고친 시험판입니다. 프로젝트 데이터 스키마 **2.3.6** 호환은 그대로입니다.

### 수정
- **도면 칸 최소 높이 보장 (D-051)**: alpha.1부터 하단 패널을 닫으면 작업 영역을 화면 높이에 맞추면서, 낮은 화면에서 도면 칸이 크게 줄었습니다(1920×890에서 674px → 277px). 이제 도면 칸은 v2.4.1 높이(약 674px) 아래로 줄지 않고, 화면이 더 클 때만 화면 끝까지 늘어납니다.

| 화면 | alpha.3 | alpha.4 |
|---|---|---|
| 1920×890 | 277px | 674px |
| 1920×1080 | 467px | 674px |
| 1600×1000 | 345px | 674px |
| 1920×1400 | — | 787px · 세로 스크롤 없음 |

- 낮은 화면에서는 v2.4.1처럼 페이지 세로 스크롤이 생깁니다.

### 그 밖의 내용
- alpha.3의 모든 기능(구조물 반영 자동 추천, 로케이션 형식 확장, 통로 최대 폭 상한 등)을 그대로 포함합니다.
- 주의(alpha.3과 같음): `2A`처럼 숫자로 시작하는 열이 들어간 프로젝트 JSON은 v2.4.1에서 열 수 없습니다.
