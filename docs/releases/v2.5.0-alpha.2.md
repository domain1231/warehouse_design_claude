## Warehouse Layout Designer v2.5.0-alpha.2 (시험판 · pre-release)

v2.5.0-alpha.1에 **로케이션 열 고정 배치 개선 3건**을 더한 시험판입니다. 실제 창고(18.44×8.5m, 대차 통로 0.8m) 검토 결과를 반영했습니다. 프로젝트 데이터 스키마 **2.3.6** 호환은 그대로입니다.

### 개선
- **기본값 = 자동 추천 (D-045)**: '로케이션 열 고정'을 고르면 처음부터 8가지 형태 중 통로가 가장 넓은 형태를 보여줍니다. 예시 창고 18.44×8.5m에서는 열 배치·등 맞댐·통로 1.22m(56/56).
- **누락 번호 처리 (D-046)**: '당겨 붙임'(기본) / '빈자리 비워 둠'(번호 줄 맞춤) 선택. 빠진 번호를 진단에 표시(예: "누락 번호 4개: C1·H1·M1·N1 → 빈자리 비워 둠").
- **장애물 회피 (D-047)**: 생성 랙이 기둥·벽·보관 불가 구역·문·보호 통로와 겹치면 그 랙과 뒤 랙들을 열 방향으로 장애물 너머까지 밉니다(열 순서·번호 순서 유지). 최대 통로·형태 추천 계산은 구조물을 빼고 한 값입니다.
