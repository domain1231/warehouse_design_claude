## Warehouse Layout Designer v2.5.0-alpha.13 (시험판 · pre-release)

alpha.12 이후 **Track C 후속(C10·C8·C9)** 공간 지표 개선을 반영한 시험판입니다. 프로젝트 데이터 스키마 **2.3.6** 호환은 그대로입니다(새 선택 필드 1개는 v2.4.1이 무시).

### 빈 랙 처리 (C10 · D-073)
- **평균 용적률**은 빈 랙(랙 용적률 0)을 빼고 계산합니다(Excel `AVERAGEIF(>0)`). 빈 랙 수는 '빈 랙' 행에 따로 표시합니다.
- **80% 미만 로케이션**은 품목코드가 없는 빈 로케이션을 빼고 셉니다(분모 = 적치 로케이션 수). 품목코드 열이 없는 자료는 지금처럼 모두 셉니다.
- **Δ 용적률 지도**: BEFORE에 자재가 있던 랙이 AFTER에서 비면 빨간 '악화' 대신 회색 **'∅ 비움(이전 완료)'**으로 표시합니다. 범례와 랙 변화 목록 필터에 '비움'을 추가했습니다.
- Excel 불러오기 Summary 대조: F4 수식이 AVERAGEIF면 대조 계산도 빈 랙을 빼고, 화면 지표가 뺀 빈 랙·빈 로케이션 수를 안내합니다.

### 공간 구성 5분해 + 보관 여유 (C8 · D-074)
- 공간 구성: 랙 / **빈 랙(빗금)** / 보관 불가 / 통로 / 보관 가능 잔여, 겹침 없이 합계 100%.
- 비교표에 **보관 가능 합계**(빈 랙 바닥 + 잔여 바닥)와 **선반 여유 용적**(선반마다 단 높이 − 최대 자재높이, m³·%) 행을 추가했습니다.

### BE/AF 면적 기준 통일 (C9 · D-075)
- 비교할 때 두 배치가 같은 총면적 기준을 씁니다. 한쪽이라도 Excel 총면적이 없으면 양쪽 모두 도면 전체로 계산하고 "면적 기준: …"을 표시합니다.
- 한쪽에만 있으면 **"… Excel 총면적 N㎡를 …에도 적용"** 버튼으로 맞출 수 있습니다(실행 취소 가능, BEFORE 잠금이면 비활성).
