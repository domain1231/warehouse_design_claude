## Warehouse Layout Designer v2.5.0-alpha.1 (시험판 · pre-release)

v2.5.0-alpha.0에 **사용성 개선 6건**과 **Excel 자동 배치 '로케이션 열 고정'(1·2단계)**을 더한 시험판입니다. 프로젝트 데이터 스키마 **2.3.6** 호환은 그대로입니다.

### 새 기능: 로케이션 열 고정 배치 (D-041)
- Excel 불러오기 → 자동 배치 방식 **'로케이션 열 고정 · 열·번호 순서 유지'**.
- 열 순서(A→B→C…)와 열 안 번호 순서를 바꾸지 않고, **창고 치수와 랙 깊이로 열 사이 간격을 계산**합니다.
- 통로 방식: 모든 열 사이 통로 / 등 맞댐 쌍(두 열씩 등을 붙임). 열 사이 간격: 남는 폭을 통로에 고르게 / 통로 목표 폭 그대로.
- 들어가지 않으면 랙을 옮기거나 빼지 않고 **부족한 길이를 진단**합니다(예: "폭 6.46m 부족 · 등 맞댐이면 1.22m 가능").
- 예시(가상 창고 18.44×8.5m, 56랙): 모든 열 사이 통로 0.70m 56/56, 등 맞댐 통로 1.22m 56/56.
- **2단계(D-042)**: 배치 축(열 배치 / 행 배치 / 자동 추천), 한 줄 열 수(1열 / 2열 — 열을 자르지 않고 순서대로 이어 놓음), 시작 방향(설정대로 / 지그재그). 자동 추천은 8가지 형태를 모두 계산해 표로 보여주고 목표 통로를 만족하는 최대 통로 형태를 고릅니다.
- 자동 추천 예시: 18.44×8.5 → 열·1열·등 맞댐 1.22m / 24×14 → 행·2열·등 맞댐 2.88m / 12×20 → 열·2열·등 맞댐 2.21m (모두 56/56).
- **행 배치 방향 이름(D-043)**: 행 배치일 때 '행 진행 방향(북→남/남→북)', '첫 랙 위치(서쪽 끝/동쪽 끝)'로 표시.
- 북쪽 방향 0·90·180·270°에서 사용. 저장 형식은 v2.4.1에서 그대로 열림(열·행·한 줄 2열·지그재그 모두 확인).

### 사용성 개선 (D-040)
- 2개 이상 삭제 시 확인 창(1개는 즉시 삭제, ↶로 되돌리기 가능).
- 하단 패널을 닫으면 작업 영역 높이를 화면에 맞춤(1600×1000에서 페이지 세로 스크롤 없음).
- JSON 형식 오류 안내: "JSON 형식이 아닙니다 (N번째 글자 근처)" — 파일 내용은 표시하지 않음.
- 정밀 입력 오류 문구 통일: "X 값을 입력하세요 · 0.001m 단위".
- 배치 도구 거부 시 사유와 해결 방법 안내(창고 범위 밖 / 공간 위반 → '공간 위반을 경고 후 허용').
- Ctrl+S 저장 결과 알림(저장됨 / 변경 없음 / 저장 실패).
