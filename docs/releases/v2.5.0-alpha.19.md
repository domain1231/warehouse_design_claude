## Warehouse Layout Designer v2.5.0-alpha.19 (시험판 · pre-release)

alpha.18 이후 **공유용 JSON(E8)**과 **큰 이력 프로젝트 편집·저장 속도 개선(D-096)**을 반영한 시험판입니다. 지표 산식·배치 계산은 바뀌지 않았습니다. 프로젝트 데이터 스키마 **2.3.6** 파일 읽기 호환은 그대로이고, 저장 원문은 alpha.18과 같습니다.

### 공유용 JSON (이력 제외)
- **저장소 관리 → 'JSON 저장 형식' 줄 오른쪽 `공유용 JSON(이력 제외)`**: 현재 BEFORE·AFTER 배치와 배치 정보, 배치별 최신 Excel 기준일 스냅샷, 설정·범례(참고 도면 포함)만 담은 작은 파일을 내려받습니다.
- 배치 백업·자동 배치 이력·명령·가져오기·재고·규격 변경 이력과 그 밖 기준일 스냅샷은 빠집니다. 원본 프로젝트는 바뀌지 않습니다.
- 받은 사람이 불러오면 비교 화면 결론 문장이 원본과 같습니다(11/02 운영 파일 0.97MB → 0.79MB).

### 큰 이력 프로젝트가 더 빨라졌습니다
- 편집할 때마다 전체 프로젝트를 문자열로 바꾸던 비교를 구조 비교로 바꾸고, 연속 편집의 저장을 하나로 합쳤습니다.
- 가상 큰 이력 프로젝트(메모리 약 64MB)에서 편집 + 자동 저장 **3.5초 → 1.9초**. 저장소 관리 창은 먼저 열리고 항목별 크기 표는 이어서 계산합니다('항목별 크기 계산 중…').
- 저장 원문은 이전과 바이트 단위로 같습니다.

### 확인 부탁
- 11/25 파일에서 편집(랙 이동 등) 반응 속도, 저장소 관리 열기.
- `공유용 JSON(이력 제외)` 내려받기 → 다른 창(또는 새 브라우저 프로필)에서 불러오기 → 비교 화면 결론 문장 동일.
- Windows Edge에서 위 항목.
