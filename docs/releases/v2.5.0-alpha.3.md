## Warehouse Layout Designer v2.5.0-alpha.3 (시험판 · pre-release)

v2.5.0-alpha.2에 **구조물 반영 자동 추천, 로케이션 형식 확장, 통로 최대 폭 상한**과 최적화·디버그 2차를 더한 시험판입니다. 프로젝트 데이터 스키마 **2.3.6** 호환은 그대로입니다.

### 개선
- **구조물 반영 자동 추천 (D-048)**: 기둥·벽·보관 불가 구역·문·보호 통로가 있으면 들어가는 형태를 모두 실제로 배치해 보고 창고 안 정상 랙이 가장 많은 형태를 고릅니다. 진단에 형태별 "구조물 반영 실제 배치 n/N"을 표시합니다.
- **로케이션 형식 확장 (D-049)**: 숫자로 시작하는 열 이름(예: `7F-2A-1-1-1`)과 로마 숫자 랙 번호(예: `2F-F-II-1-1` = F열 2번)를 읽습니다.
  - 주의: `2A`처럼 숫자로 시작하는 열이 들어간 프로젝트 JSON은 **v2.4.1에서 열 수 없습니다**(Excel 분석 시 경고). 로마 숫자 랙은 숫자로 바꿔 저장하므로 v2.4.1에서도 열립니다.
- **통로 최대 폭 상한 (D-050)**: '남는 폭을 통로에 고르게'일 때 통로가 '통로 최대 폭'(기본 1.5m)을 넘지 않고, 남는 공간은 끝 벽 쪽 여유로 둡니다(예: 10m 창고·열 2개 → 통로 8.8m가 1.5m로).
- **안내 추가**: 들어가는 형태가 하나도 없으면 창고 크기·통로 목표·랙 회전을 확인하라고 알립니다.
- **최적화·정리**: 합집합 면적 계산 결과 기억(화면을 다시 그릴 때 반복 계산 생략, 결과 동일), 쓰지 않는 코드 정리.
