# Golden Master 기준 데이터

기준본 v2.4.1의 관찰 결과를 정규화한 **가상 데이터**입니다. 운영 데이터가 아닙니다. 재구축본이 같은 입력에서 같은 결과를 내는지 비교하는 기준으로 씁니다.

- 생성 도구: 기준본 저장소 `tools/golden-master.cjs` (`docs/GOLDEN_MASTER.md` 참조)
- 생성 커밋: `domain1231/warehouse_design` chore/golden-master 브랜치(G1 입력 양자화 수정 포함) — 런타임 소스는 v2.4.1(`d7b1e69`)과 동일하며 도구 파일만 추가된 상태
- 앱 2.4.1 / 스키마 2.3.6, 일반본만 사용, Linux Chrome for Testing 153
- 결정성: 새 브라우저 컨텍스트에서 3회 독립 실행한 결과의 sha256이 모두 동일

| 파일 | 내용 |
|---|---|
| G1.json | 기하 기본연산 polygon/overlaps/gap 421쌍 (경계 사례 포함) |
| G2.json | 공간 경고와 W.scan 결과, 0~500랙 11케이스 |
| G3.json | 가상 Excel(CSV·XLSX) 분석 결과 |
| G4.json | 자동 배치 4개 모드 + 열 우선 줄바꿈, 수용·초과 창고 |
| G5.json | 프로젝트 모델(샘플·빈 프로젝트) |
| manifest.json | 생성 환경, 정규화 규칙, 파일별 sha256 |

## 비교 규칙
- ID는 Excel Key(`R.key`) 또는 순번 토큰으로 바뀌어 있습니다. 재구축본도 같은 정규화를 거친 뒤 비교합니다.
- 시각·탐색 시간·힙 크기 필드는 제거되어 있습니다.
- 숫자는 1e-9로 반올림되어 있습니다. 좌표·규격 비교는 이 정밀도에서 일치해야 합니다.
- 결과가 다르면 의도한 개선(예: D-005 결정적 탐색)인지 오류인지 PR에서 판정하고 기록합니다.

## 갱신
기준본이 바뀌면(v2.4.x 수정) 기준본 저장소에서 다시 생성해 이 폴더를 교체하고, 바뀐 시나리오와 사유를 PR에 적습니다.
